## 3.3.3

### Bugfix

* Fixed a bug where clicking the code block's hover language button while the editor had focus closed the hover UI without opening the language menu.
* Fixed an issue where the block handle and its line highlight stayed visible while typing, and were drawn over the toolbar when their block was scrolled out of the editing area.
* Fixed a bug where pasting or dropping a file failed with an error after a component's edit dialog (image, video, ...) had been opened. [#1688](https://github.com/JiHong88/suneditor/issues/1688)
