### feat

- Added row/column move commands to the table's row and column menus — moving a row or column steps it over its neighbour, and a merged region travels as one block instead of being torn apart. A direction with nothing left to move over is greyed out (`plugins/dropdown/table`)
- Added row/column drag-move handles to the table — while the table is hovered or selected, a handle appears left of the hovered row and above the hovered column (sized to the merged block when cells are merged); dragging it shows a drop indicator on the nearest legal position and drops the whole row/column there. The moved row/column stays selected as a plain cell range (cell dot included) and the handles keep following the hover. Escape cancels the drag (`plugins/dropdown/table`)
- Clicking a table move handle selects (pins) the whole row/column and opens its menu on the grip — the row/column menu plus cell properties and merge (multi-cell) or split (single cell). Clicking the pinned band again, pressing Escape, or clicking a cell releases it; the pin and its menu stay through the editor's scroll (`plugins/dropdown/table`)
- Added a `nonDragHandle` option to `Figure.open()` — a plugin can suppress the component drag handle for that open (the table uses it on hover, where the handle would overlap the column move handle) (`modules/contract/Figure`)
- Added a `dot` value to the table plugin's `cellControllerPosition` option — selecting a cell shows a small dot on the cell's right edge (left in RTL) instead of the cell controller; clicking the dot opens the controller anchored to it; clicking the dot again or anywhere else in the editor closes it like a popup, and the table stays selected. A cell click moves the dot to the new cell (`plugins/dropdown/table`)
- Added a `tableControllerPosition` option to the table plugin (`'dot'` default, `'table'`) — with `dot`, selecting the table shows a dot on its top-left corner (top-right in RTL) instead of the table controller; clicking the dot opens the controller, and clicking the dot again or anywhere else in the editor closes it while the table stays selected. A click inside the table keeps the dot itself, like the table controller in the `'table'` mode (`plugins/dropdown/table`)
- Added the `selection` and `escape` params to `Controller`. `selection: true` marks a controller as its component's selection UI: the component keeps its own keyboard/copy/outside-click handling while the controller is open (keys typed into the controller's inputs still stay with the inputs), and children inherit the flag through `parents`. `escape: 'all'` makes Esc close every open controller and end the selection at once; the default `'level'` closes one level per press — a child controller closes by itself and the selection stays, while a base selection controller leaves Esc to its component, which deselects (`modules/contract/Controller`)
- Added `ui.closeAllControllers()` — closes every open controller, last opened first, and ends the component selection (`core/ui`)
- Added controller-registry queries to `ui`: `isInsideController(target)`, `getControllerAt(target)` and `hasFloatingController()` — use them instead of inspecting `ui.opendControllers` or `.se-controller` classes directly (`core/ui`)
- Added `component.isHoverSelected` — `true` while the current selection only comes from a mouse hover (e.g. the drag handle) rather than a click (`core/component`)
- Added a `container: 'wrapper'` option to `Controller` (with a `place` callback) — an in-editor controller hosted by the current root's `.se-wrapper`: it keeps the controller contract (`parents` and the child sync, `hide`/`show`/`resetPosition`), hides with the other controllers on a drag-handle hover and moves with the editor's inner scroll in the same tick, while its owner drives its lifecycle (no auto-close listeners, no deselect on close, no editor-state changes). The table dots and move-handle strips use it. Registry queries tell it apart through the new `ControllerInfo.inWrapper` flag — `ui.hasFloatingController()` skips it (`modules/contract/Controller`)
- Added `dom.check.isPopoverOpen(element)` — whether an element is a shown popover; returns `false` instead of throwing where the `:popover-open` selector is not implemented (`helper/dom/domCheck`)
- Added `SunEditor.Module.<Name>.Instance` types for every public module class (`Controller`, `Figure`, `SelectMenu`, `Modal`, `Browser`, `ColorPicker`, `HueSlider`, `CommandMenu`, `ModalAnchorEditor`, `ApiManager`, `FileManager`) — annotate a module instance passed between functions without a relative `import('…').default` path (`typedef`)

### change

- Raw embed HTML (pasted `<iframe>`/`<blockquote>` embed code) is now cleaned at insert time with the same rules applied when the content is loaded again, so attributes the sanitizer does not allow (e.g. `class="twitter-tweet"`, `data-instgrm-*`) are dropped right away instead of only after a reload. Allow them with `attributeWhitelist` / `allowedClassName` if a widget script needs them (`plugins/modal/embed`)

- The table plugin's controllers now default to the dot launchers — `cellControllerPosition` and `tableControllerPosition` both default to `'dot'`, so selecting a table/cell shows a small dot instead of auto-opening the controllers. Pass `cellControllerPosition: 'cell'` (the previous default) or `'table'`, and `tableControllerPosition: 'table'` to restore the previous auto-open behavior (`plugins/dropdown/table`)
- The border width and color in table/cell properties now come prefilled when the target has no border of its own: width `2` (also for the table, whose 1px dashed/dotted border was hidden entirely) and the editing area's text color (`plugins/table`)

### fix

- Fixed the French table menu swapping “insert row above” and “insert row below” (`langs/fr`)
- Fixed a crash on Enter or arrow keys when the selected component is already gone, and while hovering or dragging a table edge when the resize guide line for the current root is missing (`core/logic/shell/component`, `plugins/dropdown/table`)
- Fixed a crash on controller hover and select-menu submenus in browsers that reject the `:popover-open` selector (`modules/contract/Controller`, `modules/ui/SelectMenu`)
- Fixed an allowed embed iframe loaded without its figure staying unwrapped and raising an error — the embed component is now built for it (`plugins/modal/embed`)
- Fixed embed/video format-validation errors escaping the hook error handler — `retainFormat` now follows its synchronous contract (`plugins/modal/embed`, `plugins/modal/video`, `core/logic/shell/pluginManager`)
- Fixed the link modal's bookmark list throwing a `SyntaxError` when the URL input held a RegExp special character after `#` (e.g. `#(`) — the input is now matched literally (`modules/ui/ModalAnchorEditor`)
- Security: fixed stored XSS through a forged iframe clipboard placeholder — the iframe rebuilt from `data-se-iframe-holder-attrs` kept `srcdoc` and every other attribute. The rebuilt iframe now goes through the same attribute filter as an iframe in the source HTML, and a malformed placeholder is removed instead of making `html.clean()` throw (`core/logic/dom/html`, GHSA-q867-q2hw-f8gp)
- Security: fixed event handlers surviving on namespaced-lookalike tags with digits or other characters in the name (`<a:1>`, `<a:1b>`, `<b:1c>`) — such tags skipped attribute filtering entirely. Their attributes are now filtered like any other tag's (`core/logic/dom/html`, GHSA-6pm3-2q9w-2926)
- Security: fixed `javascript:` URLs passing the sanitizer's protocol check when the colon was written as a named or semicolon-less character reference (`javascript&colon;`, `javascript&#58`) — URL values are now decoded with the browser's own HTML parser before the check (`core/logic/dom/html`, GHSA-v4jx-8pj6-w4w8)
- Security: fixed the Embed plugin inserting raw embed HTML unsanitized — event handlers, `srcdoc` and extra sibling elements were appended as-is. Raw embed HTML now keeps only its leading `<iframe>`/`<blockquote>` (plus a `scriptSrcWhitelist` script) and is cleaned with the same rules as `html.clean()` (`plugins/modal/embed`, GHSA-wxhr-f7jg-wphq)
- Security: fixed `strictMode.styleFilter: false` turning off the attribute whitelist and the URL check — `javascript:` URLs and `iframe[srcdoc]` were kept. Event handlers, `srcdoc` and unsafe URLs (now including `srcset` and SVG `values`) are removed whichever `attrFilter`/`styleFilter` setting is used, also with both off. With `attrFilter: false` every other attribute is kept instead of all but `style` being dropped, and URLs are checked against script-capable protocols only (`javascript:`, `vbscript:`, non-image `data:`), so custom app schemes such as `zoommtg:` stay (`core/logic/dom/html`)
- Security: fixed `strictMode.tagFilter: false` also turning off the `allowedExtraTags` removal — `<script>`, `<style>`, `<meta>` and `<link>` were kept. Tags disallowed by `allowedExtraTags` are now removed whichever `strictMode` setting is used (allow them through `allowedExtraTags` instead), and the removal repeats until nothing is left, so the remains of a removed tag can no longer join into a new one (`<scr<script></script>ipt>`) — also in the head HTML passed to `setFullPage()` (`core/logic/dom/html`)
- Security: fixed stored XSS from server data or content text written as HTML — file names, alt, tags and folder names in the file browser's default item renderer and search highlight (`modules/contract/Browser`, GHSA-pwf4-x78x-9937), heading text in the link bookmark list (`modules/ui/ModalAnchorEditor`, GHSA-5pp5-5qrp-vq56), the uploaded file name in `fileUpload` (`plugins/command/fileUpload`, GHSA-2w4v-r3v4-f5h4) and heading text in the `document:header` panel (`core/section/documentType`, GHSA-h9pq-57qf-vvfh)

- Fixed controllers closed by a component deselect never running their own close — `isOpen` stayed `true`, their key/mouse listeners stayed bound, `initMethod` and the host's `controllerClose` hook were skipped, and the next open of the same controller was left out of the open-controller registry. A deselect now closes each open controller (children first) through `close()` (`core/ui`)
- Fixed a selected component staying selected for good after a child controller (one with `parents`) closed — a selection controller (`selection: true`: image/video/audio/table/math/file/anchor controllers and their children) no longer takes over the component's outside-click and keyboard handling, so the next outside click deselects as usual (`modules/contract/Controller`, `core/component`)
- Fixed toolbar dropdowns and menu containers opening downward over their own button in the bottom-toolbar modes (`classic:bottom`, `inline:bottom`) instead of opening upward — the menu was measured before its tray was shown, so its height read as `0` (`core/menu`)
- Fixed the bottom toolbar (`classic:bottom`, `inline:bottom`) with a JS sticky (`toolbar_sticky.position: 'fixed'` or `toolbar_container`) pushing the content and the window scroll down by the toolbar's height whenever it stuck — its placeholder sat above the content instead of in the toolbar's slot below it. The bottom toolbar also now sits above the status bar as intended, instead of below it (`core/constructor`)
- Fixed the bottom toolbar (`classic:bottom`, `inline:bottom`) on the JS sticky engine ignoring the `toolbar_sticky` top offset at both ends of its sticky range — it unstuck one toolbar height too early and dropped below the offset line (partly out of the viewport), and near the editor's top edge it jumped by the offset when sticking (`core/toolbar`)
- Fixed Esc on an open select menu also closing what lies under it — e.g. the table's border style menu in cell properties ended the whole table selection, and a select menu inside a modal closed the modal. Esc now closes only the menu, like a child controller (`modules/ui/SelectMenu`, `core/component`, `modules/contract/Modal`)
- Fixed the table's selection outline (and the selected-cell styles) blinking off while drag-selecting cells or resizing.
- SelectMenu no longer mistakes a DOM-node item for a submenu config — a node item with child elements (e.g. a heading in the anchor bookmark list) was rendered as a broken submenu instead of a plain row (`modules/ui/SelectMenu`)
- Fixed document-type page indicator drifting out of sync with the scroll position — page offsets accumulated an error on scroll and the current-page detection used stale positions (`core/section/documentType`)
- Fixed the French translation of `resize` (was Czech text) (`langs/fr`, #1692)
- Fixed the HTML sanitizer keeping `javascript:` and other non-whitelisted URLs in the `poster` attribute of `<video>` — URL protocol checks only covered `href` and `src`. They now also cover `poster`, `xlink:href`, `background`, `cite`, `action` and `formaction` (`core/logic/dom/html`)
